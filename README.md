# Valutazioni cavalli · Versione dimostrativa

Demo nel browser del programma desktop per la gestione dei rating dei cavalli da corsa.
Tutti i dati (cavalli, corse, classi, fantini, proprietari) sono di fantasia.

## Cosa provare
1. **Classifica**: cambia la data di riferimento (per esempio 30/04/2026) e guarda come cambia la classifica; poi "Esporta in Excel".
2. **Corse**: apri il *Premio Pantalica*. Sotto "Effetto sul rating" vedi pesi assegnati, kg di distacco e rating proposto; per Vento il rating è stato deciso a mano.
3. **Cavalli**: apri *Scirocco* per vedere lo storico con la rettifica manuale di luglio.
4. **Nuova corsa**: inserisci una corsa e guarda il rating aggiornarsi mentre compili l'ordine d'arrivo.
5. **Impostazioni**: cambia le regole di calcolo; tutta la classifica si ricalcola.

Il pulsante "Ripristina dati di esempio" in alto riporta la demo allo stato iniziale.

## Differenze con la versione desktop
Nella versione da installare i dati sono salvati in un file sul PC, con backup automatici
in una cartella a scelta e ripristino da backup. Qui i dati restano solo nel browser.
